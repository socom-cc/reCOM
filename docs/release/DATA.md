## Classes

- **exact**: same size (the next prototype object is paired at the same distance, or the next paired
  release object starts where the prototype size ends) and the same bytes once pointer words are
  masked (function pointers must map through the function map, data pointers through this map);
  `.bss` counts as zero bytes on both sides;
- **deviating**: paired, with a difference or a size the evidence only bounds (flags);
- **unsure**: witnesses that contradict each other, or a pair that rests on order alone;
- **new**: a release data address code references that no paired object covers (one row per address: a
  field of a new object is a row of its own);
- **removed**: a prototype object nothing paired (`refs-removed`: only removed functions use it;
  `refs-unaligned`: paired functions use it but not at an aligned place; `unreached`: no code uses it).

Release sizes are `N` when confirmed, else `lower..upper`: the largest offset plus width the release
code accesses, and the distance to the next paired release object (`?` when none follows).
