## Classes

- **exact**: equal masked instructions and layout (address operands masked: `j`/`jal`
  targets, address-range `lui` immediates, `$gp` offsets, low halves paired with an
  address `lui` through the function's control flow), and every call and data
  operand consistent with the other pairs;
- **deviating**: the same function with differences;
- **unsure**: a candidate pair the evidence does not settle (see the unsure section);
- **new**: release function with no prototype counterpart;
- **removed**: prototype function with no release counterpart.

Similarity is `difflib.SequenceMatcher.ratio()` over the masked instruction words,
2M/(n+m) with M instructions matched in order: the share of instructions equal.
Shape similarity is the same over instructions with every immediate removed; flag
`imm-only` marks equal-size pairs whose shapes are identical, so only immediates or
offsets differ (such a pair is deviating whatever its similarity). Operation similarity
is the same over the operations alone (no registers, immediates or targets): it
survives register-allocation changes.
