## Fixes

- B, #68 CZWeapon::~CZWeapon: the ELF erases m_LegalAmmoList (0x31f80c) before its ~CZAmmoList
  (0x31f818); the port left the list full, so the member's ~CZAmmoList deleted ammo that
  CZAmmo::m_ammolist owns. Now cleared at the end of the body. Masked: weapons are destroyed only by
  ~CZWeaponList of the static weapon list, which has no ELF caller.
- B, #9 CCharacterType::UnPack: an empty packed item ends the loop (0x24adf0 branches to the
  epilogue 0x24ae74); the port skipped it and went on. Masked: remote seals only (network play).
- C, #64 / #65 / #66 the three CZWeapon::Fire: the AIE_WEPFIRE test is `c.le radius, 1` -> skip
  (0x31f05c, 0x31f1f4, 0x31f378); was `radius > 1` (NaN only).
- C, #37 CZProjectile::DoMiss: the three angle wraps `c.le angle, 2pi` (0x318dfc, 0x318e2c,
  0x318e5c) and the range test `c.le len, max` (0x318f10); were `>` and `!(max < len)` (NaN only).
- C, #38 CZProjectile::HandleTimers: the fuse `c.le time, 0` (0x318fa8) and the removal time
  `c.le removal, 0` (0x319080); were `!(time > 0)` and `removal > 0` (NaN only).

Kept deviations (reason now in the code): #53 CZDecalSet::ReadDecalEntry and #56
CZMarkList::ReadBloodDecals keep a texture that is not found out of the world's texture lists (the
decals worker's guard; the ELF passes it to AddTextureAssetDecals 0x22e290, which reads through it).

ELF quirks kept (already commented in the code): #57 ReadWeaponDecals clears the names before the
material lookup (no entry stored); #59 UnInit leaves the CDecal pools' arrays dangling; #49 Init
clears only 30 of the 60 indirect flags; #42 NetRemoveProjectile reads the state before the NULL
test; #44 PreTick ticks unused slots; #26 ReleaseFlyout's swap with slot -1 when not found; #36
GetIDType on a NULL cast; #33 the unused region and matrix; #17 / #19 the turret's inline Get and
the trigger sum in double.

Float checks: the literal words 0x4048f342 / 0x3fc8d6aa / 0x3eba5a47 / 0x3f333334 / 0x30000000
(#19, #12), 0x3e99999a / 0x3fe66666 (#57, #58), 0x3fc90fdb / 0x40c90fdb (#37); the (x2 + y2) + z2
order in #37; the products' operand order in #14, #32, #35; every compare form (the fixes above).
No float-to-unsigned conversion in this list.

Noted, not graded: char_type.cpp's zfree / zstrdup pass the port's file and line to the heap labels
(the ELF "char_type.cpp" 818-825); only the heap's bookkeeping sees them.

Leads for other lists: none new. `CFlyoutMachine::Tick` tests ReleaseFlyout's 0/1 return in the ELF
(the port's ReleaseFlyout is void, noted in its comment): worth a look when Tick is judged.

What the packets lacked: the inline IsDirectFire body and CFlyoutMachine / CDecalPool / CAiEvent
layouts (read from the headers), the epilogue of UnPack and the compare addresses (dis.sh), the
callers of ~CZWeaponList / ~CZWeapon (xref.py), the weapon list's static storage.

Runs: the default build links (`default.sh audit-mcombat-default`, HEAD dc86cb6d + this list's
files). Smoke: one fake-pad m8 run with shooting (`port/test-hooks/render/pad_fire.txt` with the state hook,
`-DSOCOM_HOOK_MISSIONS=1 -DSOCOM_HOOK_PLAY_AT=999999`, 190 s; the mission cameras skipped at 107 s, about 80 s
of play after them): no STOP or exception, the rifle fired down to 1 of 30 rounds (HUD at 150 s), heap
flat at 23.17 MB; focus kept. The B fixes are not reachable on this disc (static destructor, network
unpack) and the C fixes are NaN-only, so no targeted trace.
