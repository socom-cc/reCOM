# Audit of the large HUD functions, list B (2026-11-16, socom-port-audit-hud-b)

List `large-hud-b`: 40 functions of 700 bytes or more in `hud_bitmapreticule.cpp`,
`hud_bombmapitem.cpp`, `hud_claymoremapitem.cpp`, `hud_devtext.cpp`, `hud_main.cpp`,
`hud_newhudmap.cpp`, `hud_objectives.cpp`, `hud_pausemenu.cpp`, `hud_playermapitem.cpp` and
`hud_scorepopup.cpp` (62 KB). Judged in the scan's rank order (`scan-large-hud-b.md`), each
compared with its packet's ELF disassembly instruction by instruction (AUDIT_PLAN.md "What
correct means"). Started on HEAD d17cfec1; HEAD moved to 4719c92e meanwhile without touching
these files or the two shared headers. Every float constant of the judged bodies was checked
against the ELF word (rounded to nearest and truncated, [float-constants.md](float-constants.md)).

## Fixes (ELF evidence)

- A, #30 CZNewHudMap ctor 0x3c6790: the horizontal grid loop is entered at its test (`b`), whose
  delay slot loads 8.0, so all seven lines get alpha 8; the port gave line 0 alpha 128 (it had been
  read as a quirk), a bright white line across the full-screen map (SELECT). Seen gone in run tm1.
- B, #3 BitmapReticule::UpdateAccuracy 0x3ce4e0: the miss-X test has a `CBody::m_state == 9` term
  (lb +0x11d) after m_retblocked that the port left out (m_state protected): added, with
  `friend class BitmapReticule` in zbody.h (edit file).
- C, #8 BitmapReticule ctor 0x3d0650: m_lase_str / m_detonation_str start as "UNUSED" (0x465c58).
- C, #19 CHUD ctor 0x3bc180: the inline ctors of CZActionBitmap (textures and m_parent zeroed, not
  m_canDropMPBomb / m_actionXTexture), CZStaticRadioBitmap and CZDynamicRadioBitmap (all zeroed)
  were missing (hud.h, edit file).
- C, #15 CHUD::ZoomOut 0x3b8a50 (and #14 ZoomIn): zoomtext$2973 is 10 bytes, the 11-12 byte text
  runs into the ELF's 6 bytes of padding; the port's buffers are 16 bytes now.
- C, #5 BitmapReticule::HudTick 0x3cf070: no -1 test before m_reticuleTex[m_rettype] (index -1 is
  m_rettype itself, not NULL): the position follows the kit for type -1 too.
- C, #29 ~CZNewHudMap 0x3c6490: the items are deleted from the back (the sentinel's +0 node;
  front() 0x2d8b50 reads +4).
- C, #28 InitMap 0x3c5d90 and #20 TickFullScreenAnims 0x3c3790: the grid spacings are the words
  0x41236492 (10.2120533) and 0x42236492 (40.8482132), not 10.212296 / 40.848.
- C (compare forms, NaN only): #6 ThreatDirTick W+S angles, #35 CZPauseTest::HudTick clamp, #24
  HandleScrolling, #13 SetupFiremode and #12 SetupAmmoCount zoom tests, #3's four diagonals.

## Kept deviations (reasons in the code)

- #11 StatusLine: the small status tests appCamera->m_entity for NULL; the debug bars' z / w are 0
  (the ELF leaves stack contents).
- #16 CHUD::Tick: OrdersMenu::HandlePad is not called without a pad.
- #14 ZoomIn: prints into its own buffer (the ELF into ZoomOut's zoomtext$2973).
- #38 TickSealCone: the death swap does not copy textures into the clipped fans (C2DTriFan has no
  texture member yet; its Clip is empty).
- #37 SetViewCone: blip 9 reads the row past `_blips` in the ELF; the port uses black.

## Leads for other lists

- [tacmap.md](tacmap.md) "ELF quirks kept" calls the bright first grid line an ELF quirk: it was
  this defect (#30); that bullet is out of date.
- zTwoD (draw list): C2DTriFan has no texture member and an empty Clip, so the player items'
  clipped fans never draw (#38).
- Compare forms (`>` for `!(<=)`) are likely common in other modules' float tests.
- Static text buffers sized as the ELF's symbol but written past it into the ELF's padding (as
  zoomtext$2973) are worth a look elsewhere.

## What the packets lacked (fetched)

About 15 fetches over 40 rows: the port's file-local helpers a body calls (AddLabel, StepDown,
ResolveIndex, TaskPeak, BenchInterval, BombPlace, ClaymorePlace, CalcDrawPos, SetMapScreenPos,
hud_zoomtext, hud_num_connected_text); DWARF offsets of members only reached through raw offsets
(BitmapReticule +0x31b0.., CZPauseTest +0x358, the inline-ctor members of CZActionBitmap and the
radio bitmaps, CZKit +0x4..+0x10, CSealCtrlAi +0x68 / +0xa8); the texts of `@NNNN` strings shown
without text (empty strings, '-', ' '); the MSL list node layout (front() / tail()); enum values
(PAD_BUTTON, KEY_STATE, MENU_STATE) and gopt field offsets; the port ELF's symbol layout (for the
zoomtext overrun).
