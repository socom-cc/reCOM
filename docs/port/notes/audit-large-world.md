virtuals now in the ELF's slot order inside the skeleton region; GCC's two dtor slots and its vptr
placement remain). Effect: none visible: `CLight::SetActive` 0x224b00 is the same code as
`CNode::SetActive` 0x17d2b0, and no other override changes behaviour; the run shows it reached.

## Fixes

- B, #4 NodeGetAltitude: the floor DIs go through vtable +0x14, `GetIntersect` (0x211450); the port
  called `GetAltitude` (+0x18), an unbounded vertical probe without the back-face mask. In the m8
  run 8,842 of 761,856 probes differed, all but two only in the hit height (0.01 .. 0.07 units),
  one hit / miss each way: masked on this disc.
- B, #18 CSaveLoad::Load: a failed Open returns NULL (0x22a21c); "LensFX_NVG" goes to
  `m_lensfx_nvg` (0x22a2cc, was `m_shadow_vector`); "NightMission" is a 4-byte int fetch (0x22a29c,
  was bool); the three vectors share the ELF's one buffer; the camera half FOV is 0x3f1c61aa (was
  0x3f1c2ea1).
- B, #19 LoadAssetLib_PS2: a missing palette file returns false at once (0x22adc0); a load result
  only clears the return value.
- C, #7 GetIntersectBatch: the extents' minima in the ELF's "unless min < value" form (0x213920).
- C, #9 CGrid::Create: the cell index clamps as min(index, count - 1) (0x215564, 0x215590).
- C, #16 InitNodeParams: `m_mtx_is_identity` / `m_NOTUSED` left alone as the ELF does.
- C, #27 VuUpdate: the `m_decals` size guard removed (0x30b5a8).

Kept deviations (reasons in the code): #25 ApplyDecal's vid / NULL-buffer guard, #23 ~CWorld's
`m_shadowTexH` NULL test, #30 SetBuffer's resize of `m_buffers`, #16's bbox left as is without a
source (the ELF copies an uninitialised stack box); the CWorld grid held through a pointer (DWARF
+0x670 by value).

record; #22 an empty AZIMUTH / ZENITH / SPEED array read anyway; #13 an instance child returned as
NULL; #10 an empty free list's NULL atom written through; #17 each DI's point 0 skipped; #28 the

transforms (x r0 + y r1 + z r2 + r3 w) in #6, #5, #4, #20, #25, #29; the NaN forms of the min / max
