# Audit of the medium zFTS functions, list medium-fts (2026-11-19, socom-port-audit-mfts)

List `medium-fts` of the correctness audit ([AUDIT_PLAN.md](../AUDIT_PLAN.md)): the 86 fenced
functions of 200 to 699 bytes (32,324 bytes) in 13 files of `src/gamez/zFTS/`. Judged file by file
in the scan's rank order (`build/port/audit/scan-medium-fts.md`), each body compared with its
packet's ELF disassembly instruction by instruction (operand order, widths and signedness, float
operation order, constant words, call arguments, stores, guards), including the port helpers that
stand for the ELF's inline code (GetCustomCharTypeName, the inline `_zrdr` Get / GetInt / GetReal,
GetBBox, CPnt3D::Cross, ftsNetworkGameInit, DMEJoinGameServer, RemoteSealPostUpdateCallback).
HEAD e1d74ced, then 1be01c4d (other lists' commits; no zFTS file changed). The network files
cannot run on this disc: their rows are read-only evidence, without a trace.

## Fixes (ELF evidence)

- B, #21 CMission::CMission 0x1f94a0: the body was empty with a NULL save manager; rewritten from
  the ELF. The module joins theMemCard.m_game (0x1f94bc, the saved-games manager), and the ctor's
  stores are made: m_winlossinc = -1 (0x1f966c; nothing else writes it, so the port's win / loss
  timer never counted down), player_grid_spacing 15 (Read does not reset it), the see-farther
  factors 200 / 300 (0x1f9720 / 0x1f9728; Read keeps them when mission.rdr lacks the tags), the AI
  defaults, the satchel fuse 10, "UNKNOWN", "ui/assetlib/junk_name", the team valves and readers.
- B, #11 CMission::OnMissionStart 0x1f4510: the five end valves get the inline Set(0) unchecked,
  callbacks only for a set valve (0x1f4544-0x1f460c; the port NULL-tested them and ran the
  callbacks every time); CSnd::m_listenerIsValid cleared (0x1f474c / 0x1f4758, the port set it
  true); the network CPickup::Open (0x1f4774) restored; "mission" fetched after "common" starts.
- B, #73 GameSignalPacketHandler 0x202000: a terrorist late joiner is NetworkTeam(0x80000100)
  (0x202224: the `lui 0x8000` sits in the branch's delay slot), the port passed 0x40000100.
  Network only.
- C, #16 _OnMissionComplete 0x1f6dd0: online, CZProjectileList::Clear only with a player
  (0x1f6e80), the port called Clear(0) without one.
- C, #64 CMissionObjectiveCam::Set 0x20a960: the line vector is swapped with an empty one after
  the clear (0x20aa08, the buffer freed).

Kept deviations: none new. The earlier lists' decisions in these files stay (audit-large-fts,
mod-zfts).

ELF quirks confirmed and kept (noted in the code already): FadeToEndMissionTick clears
m_DelayEndMission and then tests it; the unit matrix twice in CreateLadderTable and
ftsNetworkPlayerInit, the unused one in GetClosestAction / GetClosestLadder; the empty spawn list
still uses up a spawn (CSpawners::Tick); ParseTeamBlock's out-of-range team becomes the mask;
RequestTeamSwitch's second FindNextSealIndex; the stack byte +0xf of the bomb state and the unset
HitPacket bits; Write(stdout) of the persona and chat lists; the unchecked objects and net games
the code notes.

Leads for other lists: none outside zFTS. The port's TypeBombStatus uses int-sized enums (the
ELF's two states are bytes at +0 / +1, so every later member sits 4 bytes on in the port); it is
self-consistent and only the port reads it.

What the packets lacked: the inlined helpers' bodies when they live in another file
(ftsNetworkGameInit, DMEJoinGameServer, RemoteSealPostUpdateCallback, read from the source); the
values of port enums the packet did not resolve (ACTION_TYPE, SEAL_CONTROL_TYPE, MP_MAJOR_GAME_STATE,
KEY_STATE); the CNetClock, CZNetGame byte-flag and TypeBombStatus layouts (from the headers). One
disassembly annotation was wrong: at 0x202224 the annotator followed the not-taken path's
`lui 0x4000` and printed 0x40000100, where the delay slot's `lui 0x8000` holds (the port had
copied that value; checked with the reference disassembly). Addresses cited were taken from
`ref.dis`, not counted from the compacted lines.

Runs: the default build links (`default.sh audit-mfts-default`); smoke for the constructor and
OnMissionStart (boot, memory lifetime): `gate.ps1 -Only roundtrip` on this tree (menus, m8,
menus): PASS, 4 returns, in use 18,657,916 B flat. Five address comments were corrected after
the runs (comments only). The network fixes have no run (no network game offline).
