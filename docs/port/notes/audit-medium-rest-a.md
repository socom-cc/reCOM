# Audit of list medium-rest-a (2026-11-19, socom-port-audit-mrest-a)

95 functions (34,128 bytes) in 14 files: zSound (zsnd_csnd, zsnd_csndgroup, zsnd_csndinstance,
zsnd_csndsequence, zsnd_jukebox), zReader (zrdr_archive, zrdr_edit, zrdr_file, zrdr_local, zrdr_main,
zrdr_parse) and zNetwork (zNetCnf, zNetDme, zNetVoice). HEAD e0270b9a. Judged file by file in the
scan's rank order, each over its whole address range, against the packet's disassembly (addresses
and delay slots relied on checked in `build/port/boot-auditkit/ref.dis`). The zNetwork rows cannot
run on this disc (no online play): read-only evidence against the ELF. One function off the list,
`zrdr_toREAL` (same file as #44, no list yet), was judged and fixed too (row "extra").

Fixes:
- A (off the list), zrdr_toREAL 0x23d3b0: value i to output[i] (0x23d404..0x23d454); the port's loop
  ran from 1 to size - 1 and put every value into output[0] through an s32, so every character
  gear item's offset and rotation (CCharacterType::Open) held two uninitialised floats and a
  truncated third, and the zAnim command tables read one value per row.
- B, #43 zrdr_findPNT3D: needs four nodes (slti 4, 0x23d268; the port accepted three and read z past
  the array); another type leaves its axis.
- B, #92 CSndJukebox::Play: a request of a lower mode than the queued one changes nothing (the slt
  and branch over both stores, 0x2f141c / 0x2f1470); the port lowered the queued mode and kept the
  sound, so a queued mode-2/3 sound could be dropped or a queued fight request become stealth.
- C, #34 CRdrFile::Load: a reader that does not resolve is deleted and NULL returned (0x23c318); the
  block tagged "zrdr_file.cpp" 232.
- C, #35 CRdrFile::Resolve: rewritten from the ELF (resolveA's node address, the root offsets, a
  non-array root's table size: 0x23c40c, 0x23c418, 0x23c464, 0x23c4b4, 0x23c4d0); Load only calls
  Resolve(false) with an array root, unchanged on this disc.
- C, #42 zrdr_findPNT2D: another type leaves its axis (0x23d1ec).
- C, #44 zrdr_toINT: value i to output[i], another type left (0x23d4e4..); its callers pass size 1.
- C, #30 CRdrEditor::pop: only the type byte and the length are taken (0x240e20..0x240e3c), the
  reader's flag byte kept.

Kept deviations (reasons in the code): #84 / #85 the NULL-parent type read at address 0x20 answered
false (the inverted type test is the kept ELF quirk); #71 the Get(0) NULL guards (as large-rest's
LoadCSnd); #15 a fix freed with delete (mod-znet).

ELF quirks kept (in the code, unchanged): #83 the forced-loop branch that does not advance its
iterator; #77 the pool count after a removal-list grow; #81 pending instances dropped from the list;
#94 m_playlists_loaded never set; #59 the uncleared directive word; #16 server_ip / server_port
copied unchecked; #65 a missing name's offset unset in the ELF (port 0).

Float checks: CalcVolPan's (x x + y y) + z z, the attenuation and ((1024 att) master) volume order,
the pan constant 0x42652ee1 and z * -1; SetGroupVolTemp's float(old) * pct; the NaN forms of the
fade tests (#62, #63, #82, #83) as the ELF; the group pick's 2^-31 (0x30000000 = the port's
4.656613e-10f); fptosi in CalcVolPan / SetGroupVolTemp / zrdr_toINT / findint / findIPNT2D is
float-to-signed (the port's (int)); no float-to-unsigned conversion in the list.

Leads for other lists:

  (new 44 at 0x23c290) does not have; unused.
- zSystem: `zSys.isCdBoot` is +0x1d in DWARF, +0x21 in the port (known; self-consistent).
- CSnd::m_listenerIsValid (cleared at mission start since the fts list): only CalcVolPan reads it
  here (0, 0 until the next PostTick, as the ELF).

What the packets lacked: the 12-byte member-pointer constants the CNetCnf jobs push (0x43d338,
0x43d3e8, 0x43d428, 0x43d468, 0x43d488: read from the ELF file and matched to StartState,

calls (`vt.py 0x472a20`), CftsPlayer::IsInside's body (ref.dis), the CHNetCnf job offsets and the
CNetCnfInterface / CSTable / CRdrFile layouts (headers), and an exact address inside the compacted
listing of #43 (ref.dis).
