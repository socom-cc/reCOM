# Audit of list medium-net-a (2026-11-19, socom-port-audit-mnet-a)

81 functions (30,564 bytes), all in `gamez/zNetwork/zNetMedius.cpp`. HEAD dc86cb6d (zNetwork
unchanged up to 1c855f56). Judged in the scan's rank order, each over its whole address range,
against the packet's disassembly (addresses and delay slots relied on checked in
`build/port/boot-auditkit/ref.dis`) and the request / response layouts in
`port/compat/include/medius.h`. zNetwork cannot run on this disc (no online play): every row is
read-only evidence, without a trace.

Defect rate 4 / 81 (2 A, both the same helper; 2 C).

Fixes:
- A, #24 cbFilterChat and #37 cbChatMessage: their inline chat display (0x324f74..0x325050,
  0x328f74..) was `LobbyShowRoomChat`, which called itself (endless recursion: a crash on every
  chat line sent or received online; lead of audit-large-combat). Written from the ELF: no
  MEDIUS_CHAT_RECV_VAR -> nothing, CRdrEditor push(NULL), FindRoom of the lobby name, each line
  "%s: %s" (name +0x1c, text +0x40) in a 256-byte buffer, pop, Write(stdout), Set.
- C, #54 cbGetMyClans: the clan_badge Set is not NULL-tested (lhu at 0x32b1e0); LobbySetValve.
- C, #8 cbGetClanMemberDescriptions: the NumClanMembers Set is not NULL-tested (0x3233c0);
  LobbySetValve.

Kept deviations (reasons in the code; all decided by mod-znet2): strncpy where the ELF memcpys a
fixed size past a shorter string (#21, #23, #46, #47, #55, #56, #59, #61, #64, #70; #46's comment
made explicit with 0x32a4a8), #57's password left zero, #36's unset +0xc of the init parameters
zeroed, #22's non-string description as "", #72's strict sort comparator.

Leads for other lists:
- `_zsys_public` in `zsys.h` has a `sprPacketBegin` member DWARF does not have (DWARF:
  sprPacketEnd at +0x10, timerTicksPerSecond at +0x20; the port's is at +0x24). Self-consistent in
  the port; a layout lead for whoever owns zSystem.

What the packets lacked: the Medius request / response layouts (`medius.h`, read for almost every
row: the stack-frame offsets are only meaningful with them), the RoomGame / ClanInvitationItem /
BriefingRoom member offsets (source), DWARF of `_zsys_public` and CZNetGame (`dw.py`), the bytes of
the three one-byte speed-icon strings at 0x45b5d0 (read from the ELF file), and the address of
every inline CValve::Set's unchecked load (ref.dis).

Runs: the default build links (`default.sh audit-mnet-a-default`, HEAD 1c855f56 + this list's
file). Smoke: the default build boots to the main menu (dlgMenu at 25.9 s, no STOP; run
`mneta-def`, 40 s). The fixes are online-only.
