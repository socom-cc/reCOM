# Audit of list medium-anim-b (2026-11-19, socom-port-audit-manim-b)

68 medium zAnim functions (27,424 bytes) in `gamez/zAnim/anim.cpp`, `anim_main.cpp`,
`zanim_anim.cpp`, `zanim_sequence.cpp` and `zanim_set.cpp`. HEAD 0e13d498. Judged in the scan's
rank order (then file by file for the small ones), each over its whole address range.

Method: each function was read instruction by instruction against the port's body, with the
helpers the ELF inlines read from the source (RemoveAnimFromWorld, GetNodeRef, Running,
SeqSetState, CBlendable::Clear, CZAnimEx::Reset, LinearWeight / quadW, CNodeVector::GetNode,
CZAnimSet::Anim) and the bitfield positions of `_zanim_anim_params`, CZAnim's counters,
`_zanim_node_ref`, `_zanim_node_save`, `_zsequence` and `_zanim_cmd_hdr` checked against the
ELF's shift pairs.

Defect rate 11 / 68 (B 1 / 68).

2026-11-20 (audit-closeout): kept guards removed, now DEFECT-FIXED C: #10, #12, #13, #14, #15 (the user's rule: the prototype's behaviour is kept; see [audit-closeout.md](audit-closeout.md)).

Fixes:
- B, #19 CZAnimMain::GetAnim: the ELF tests each set's address before asking it for the anim
  (0x1c4424, 0x1c4464), so with no set list it answers NULL; the port called
  `CZAnimSet::Anim` through a NULL set. The two tests are added as the ELF has them (GCC keeps
  them: `beqz a0` before both calls in the default build).
- C, #35 CZAnim::CreateRootNode: the ELF inlines GetNodeRef (0x1cb040), NULL for root index 250 as
  well as 0; the port indexed the list for 250. Now calls GetNodeRef.
- C, #56 CZAnimMain::NetworkReceive: the argument-size test is unsigned (`sltiu 9`, 0x1cf510).
- C, #58 CSequence::Weight, through the port's LinearWeight (0x1dc820, not on this list; the ELF
  inlines the same code): total = down + (up + hold) (0x1dc830) and the three tests in the ELF's
  NaN forms.
- C, #61 CZAnimSet::LoadSIScript: the new entry is indexed by the call's own counter (0x1c5c38), not
  by m_si_script_count (the same while a set starts empty).
- C, #67 _store_frame_data: the change limit is the float 1e-5f widened to double
  (0x3ee4f8b5_80000000), not the double 1e-5.

Kept deviations (reasons now in the code): the seqname NULL tests of ActivateSequence (#15),
PauseSequence (#13) and SequenceRunning (#12), as StopSequence (#14) already recorded, and the
world-name NULL test of GetDatabaseNode (#10), where the ELF strcmps GetName's NULL as is; the
zeroed count slot of CZAnim::Load (#27) and CZAnimSet::Load (#62), unset in the ELF for a missing
key; MakeClones' walk to the last copy (#46): the ELF loop at 0x1cd018 never reloads its pointer
(five short-loop nops), so an anim that already had a copy would spin forever; Start calls it only
on a set's first start, when clone anims have none.

ELF quirks kept (already commented): ZAnimWildcardApply's digit index stopping at the count (#4),
CZAnimSetSave::Reset deleting from an unchecked current parent (#60), AddNetworkPacketArgs taking a
type-9 argument as a list (#50).

Float checks: the three-term sums in #59 ((x*x) + z*z by mula / madd, the unit_y dot
(x*ux + y*uy) + z*uz) and #16 / #22's timer sums (timer + (before - left)) are in the ELF's order;
#58 now is too. Literals 0x41200000 (#1), 0x40400000 (#68), 0x3c23d70a, 0x3fc90fdb, 0x3f7d70a4,
0x3fb2b8c3 (#59) equal the port's spellings. No stack-passed arguments (SIScript's last three bools
in t0..t2, ActivateEx's varargs from a1). No startup-computed constants.

Leads for other lists:
- zanim_anim / anim_main (not on this list): CZAnimMain::ResumeSequence 0x1c36c0 and
  SequenceExists 0x1c3600 have the same seqname NULL test without the deviation comment.
- zanim_sequence.cpp: LinearWeight 0x1dc820 was fixed here (see #58); its own row should note it.
- zanim.h: `_zanim_sound::stop_on_exit` is bool in the port, a halfword in the ELF (StopSounds
  reads `lh` / clears `sh`); harmless while GetSoundRef memsets the entry (as audit-large-anim-c
  noted).

What the packets lacked: #46's loop showed `move a3,v1` then the `bnez` with nothing between, as
the cached disassembly elides the zero words; `dis.sh -z` showed the five nops. #35 lacked the
port's own GetNodeRef body (out of line in the port, inlined in the ELF) and #58 LinearWeight and
quadW; #1 and #50 the values of the enum-class / nested enumerators (computed from zanim.h);
#2 the values of the two fill words 0x4750a0 / a4 (read from the ELF: 0xffff); #10
CNodeVector::GetNode, #39 / #43 Running, #47 CZAnimEx::Reset (read from the source). Otherwise
sufficient.

Runs: the default build links (`default.sh`); `gate.ps1 -Only roundtrip` on this tree: PASS (4
returns to the menus, heap in use flat at 18,657,900 B).
