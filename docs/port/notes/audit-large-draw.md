# Audit of list large-draw (2026-11-16, socom-port-audit-draw)

The 35 large functions of zCamera, zParticle, zTwoD and zRender; 56,892 bytes. HEAD 61e63e7e.
Judged in the scan's rank order, each over its whole address range.

Defect rate 12 / 35 (34%); without the NaN-form compares (5 rows), the removed guards (2) and the
other C rows, 2 / 35, both masked on this disc.

## Fixes

- B `C2DWidePolyline::SetSegments` 0x2fd370: each quad's triangles are (curL, prevL, prevR) and
  (curL, prevR, curR) (0x2fd9c0, 0x2fd9e0); the port's two shared a side and left a quarter of
  every wide tactical-map segment undrawn (no wide lines on m8).
- B `C2DMessage_Q::Init` 0x200ba0: the background bitmaps' virtual calls are C2D::On (vtable +0x1c,
  0x200dc8 / 0x200e30) and C2D::Off (+0x18, 0x200e60 / 0x200ea4), not TickFade and Reset.
- C `CAppCamera::UpdateDeathCamState` 0x1e9620: the first flash's timer is fade_out + 0.5 * faded
  at run time (0x1e9850), not the constant 0x3e99999a.
- C `C2DFont::Load` 0x2fea10: the element helpers' NULL tests the ELF lacks removed (0x2fec14).
- C `Particle::CreateVisuals` 0x232ea0: a NULL next vertex stops the walk and the header is
  written through it (0x2338c8, 0x233a30), as the ELF.
- C `C2DString::MakePacket` 0x302780: height scale * (factor * h) (0x3029d4); the CNT tag's ADDR
  word is left (0x302b80-0x302b98).
- C `C2DBitmap::MakePacket` 0x3031c0: the second XYZ2 keeps the first corner's z (0x3034cc), quirk.
- C `Particle::Instance::Render` 0x236a90: opacity <= 0.01 (0x236ba0); OutputOnceOnly set once and
  only cleared at the cap (0x236cf4).
- C NaN forms: `Destruction_Instance::Tick` 0x236594, `Source::Tick` 0x239768 / 0x2397e8,
  `CPipe::RenderVisual` 0x2426ac / 0x24280c, `CPipe::CAlpha::Add` 0x242270 / 0x242310 / 0x242394 /
  0x24243c.
- Lead settled: ztwod.h's stray `bool C2DBitmap::GetTrans() const` removed (the ELF has only
  `GetTrans__9C2DBitmapFv` 0x3037d0, the float one; never defined or called).

## Kept deviations

None new. Already commented in the code and judged harmless: `C2DString::MakePacket` zeroes the
GS-ignored upper UV / first-XYZ2 words; `Particle::Source::Source` sets m_active (the ELF's zeroed
heap gives the same).

## Leads for other lists

- `docs/port/notes/float-constants.md` row "camera.cpp 1147 UpdateDeathCamState `fade_out + 0.5f *
  faded`" is now stale: the ELF computes it at run time, the line is an expression again.
- The `CActionTxtrMachine` m_driver offset (+0x3cc port, +0x3f0 ELF): no function on this list
  reads it (HUD list).
- `zdb::CNode::FindChild` / `SetActive` are virtual in the ELF (CNode vtable +0x24 / +0x34; called
  that way by AttachTo, the death-camera re-targets and ClipCameraChord): the world list's znode.h.
- Layout offsets consistent within the port: theMission m_DelayEndMission (+0x70 ELF), CZSealBody
  m_fwdlook (+0xf60 ELF), CWorld holding the CGrid by value (+0x670).

## What the packets lacked

- #24 RenderWorld and #29 C2DFont::Load showed only the file-local helpers above the function, not
  its body (read from the files).
- Vtable slots: C2DBitmap's (+0x18 Off, +0x1c On, +0x20 SetTrans, +0x2c Reset), fetched with
  `vt.py 0x472d30`, which found the #34 defect; CNode's / CWorld's slots.
- Enum values (CAM_DEATH_STATE, ZVIS_FOV, the TexPhase rows CHARSETCOMMON 2 / ALPHA 11 / HUDSET1
  12), the CNode / CCamera / CTexture bitfield positions (`off.py`), short strings (0x44e808 " ",
  0x44e810 ""), the helper bodies QueueMessage / ParamsSample / the particle packet helpers.
- The members-touched labels mislabel stack and record offsets (#6's command record as
  m_matrix, #23's chain words); #24's part split dropped no labels this time.

## Runs

- Default build of the final tree links (audit-draw-default).
- audit-draw-smoke (fake pad `common/pad_start.txt`, no hook, 185 s): the mission starts at 54.6 s,
  runs to 185.6 s (about 110 s after the cameras) with every frame's RenderWorld traced, no STOP or
  exception, focus kept; heap in use 22.73 MB at the start, 23.15 MB at the end. No before / after
  pair: neither B fix changes what m8 draws.
