Defect rate 5 / 59 (A 1, B 1, C 3).

Fixes:
- A, #35 CValve::Parse 0x2f6180: rewritten from the ELF. The entry's type word (strcasecmp PERM /
  TEMP / PERSIST, 0x2f6230..0x2f6290) now types a new valve, the value is set with the change test
  and callbacks on new and existing valves, an existing valve takes PERM / PERSIST as Create does
  (0x2f6348..0x2f63bc), new valves go to the list's end (0x2f630c) and the result is whether the
  tag was found. The port made every global_valves.rdr valve PERM, so the persistent ones (the
  controller settings STEREO / INVERT_PITCH / VIBRATION / SUBTITLE_CONTROLLER, the incr_miss_* and
  GameComplete records) were left out of every memory-card save (Serialize writes type 3 only).
- B, #53 zVid_Assert 0x307a40: a failed assertion fills the shown frame in the mask's colour first
  (picframecode[4] FRAME_1 = displayBuf / 0xa0000 / disp_psm << 24, [12] RGBAQ = mask with Q 1.0,
  FlushCache, sceDmaSendN 43 qwords, sceDmaSync: 0x307a7c..0x307ae0); the port's reason for leaving
  it out ("no copy of the GS packet") was stale. Reached only on a failed allocation.
- C, #59 zvid_SetVideoMode 0x3087e0: sceGsSyncV(0) on every path, `sync` never read (0x30890c,
  0x308818); compat ignores the mode.
- C, #50 CVideo::RestoreImage 0x308c20: the image buffer's tags "zvid_draw.cpp" 454 / 482.
- C, #26 CZSIObject::Read 0x1dde20: the key blocks' tags "si_object.cpp" 166 / 167 / 168 / 171.

Kept deviation (reason in the code): #43 CValveSaveManager::UnSerialize starts each entry's value at
0 where the ELF reuses the stack word when VAL is missing (Serialize always writes it).

ELF quirks kept (in the code, unchanged): #2 the script list emptied before zBoneUnloadAll; #14 the
PopTo search without a lower bound; #12 ZAnim closed twice; #46 / #48 / #34 the valve-watch and
debugValve walks without effect (left out); #10 the init-guarded l$546.

Float checks: GetRotRaw's 0x3c23d70a / 0x3f7d70a4 and the NaN forms of its tests, GetPosRaw's
pa + t (pb - pa), GetVelRaw's (tScale (float)frames) / tf, ReadLIP's !(t <= 0), zVid_Init's
0x477fff00 / 10 / 1, SetVideoMode's 15750 / 15625 / 28800, SetDynamicLOD's ageFactor words: all as
the ELF. No float-to-unsigned conversion in the list.

Leads for other lists:
- zVideo: `pcrtcDo` is +0x59 in the ELF, +0x55 in the port (zVid_Init, zvid_MpegReset: recorded,
  header unchanged); zvid_SetVideoMode's `sync` argument is unused in the ELF (callers unchanged).
- zValve / zFTS / zUtil: with #35 the config save (theMemCard.m_config) now carries the 30 persistent
  valves CValveSaveManager writes ("PersistentValves"); a card saved by an older port build has none,
  and LoadConfig then keeps global_valves.rdr's values.
- port tools: `vt.py` fails on a vtable symbol name (IndexError); it works with the address.

What the packets lacked: the remove_if / CValveOpDelete predicate body behind Close / Reset
(0x2f6ee0, dis.sh); CGameState's vtable slots (vt.py 0x4714d0); the data words of SetDynamicLOD's
tables (sym.py, fl.py); the string at 0x44cbe8 (sym.py -s); the run-time content of
global_valves.rdr (the disc's data) behind #35's grade; that the +0xb0 word of boneArchive has no
writer (a search of ref.dis).
