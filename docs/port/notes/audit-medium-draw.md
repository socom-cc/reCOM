## Fixes

- A `CAppCamera::TickCameraWiggle` 0x1ea710: the shake moves the camera's m_screenOffset (+0x450 /
  +0x454, which feeds the clip-to-screen matrix) by w * cosf and 0.5 * w * sinf of
  PI * (2 * t) * inv_rate, w = (1 - t / duration) * (amp * scalar), zeroed after the duration
  (0x1ea74c). The port wrote the integer GS scissor rect m_screen.right / bottom, used the phase
  for cosf and a double 0.5: no camera shake on firing or near explosions, and the rect's right /
  bottom zeroed after each shake.
- B `CAppCamera::CAppCamera` 0x1eb7a0: the inline WiggleScalar(1) (0x1eb930) sets the scalar with
  the echo off and only raises it with the echo on; the port had the two branches swapped.
- B `C2DFont::GetEntry` 0x2ff260: the last fallback is (u32)(s32)c % (u32)count (divu 0x2ff31c);
  the port's signed `%` gave a negative index for a character of 0x80 or above.
- C `CPipe::CPipe` 0x246440: m_terrain 1 (0x246460, never read); m_DelayedNodes resize(48)
  (0x246554), not reserve.
- C `C2DString::UpdatePos` 0x302020: (f32)(line >> 4) * (scale * factor), scale * factor first
  (0x302094).
- C NaN-only compare forms written as the ELF: `clip3DLine` (4 args) 0x2ffd94 / 0x2ffda4 /
  0x2ffe04, `Props::GetColor` 0x237af0 / 0x237b34, `Props::GetScale` 0x2379f0,
  `Instance::List::Tick` 0x23724c, `CPipe::CAlpha::Render` 0x241db0, `CCamera::GetFogVisibility`
  0x1e8668 / 0x1e86e8.

## Kept deviations

Both already commented in the code: `InterruptFromVIF1` 0x2461d0 tests m_chainp before the D2
kick (an emptied alpha buffer the ELF never has, camera.md); `C2DString::Load` 0x3023a0 tests the
font texture before reading its height (the ELF reads low RAM through NULL).

## Leads for other lists

- `Particle::Props::GetTexture` 0x237c80 (zparticle_instance.cpp, not on this list) has the same
  `fraction <= t` walk as GetColor / GetScale: check its compare form against the ELF.

## What the packets lacked

  stateProne 2, SEAL_PEEK -1 / 1); the zSys member offsets (#4).
- Port-only struct layouts and bitfields: `_camera_params_cmd` (#21), `tag_DelayedNode` (#53, #54),
  `tag_VIS_PARAMS` bits (#38); DWARF member names at offsets the packet showed only by number
  (CCamera +0x450 m_screenOffset for #5, CPipe +0x639 m_terrain for #60, tag_NODE_PARAMS bits).
- The packet labels a command record's flag word as `timeless` (#21: arg0 typed as the 4-byte
  header) and the fallback delay-slot `lui` pairing in the scan (#8, 0x40203333) misleads.
- Helper bodies in other files (CMatrix::Transform, CNode::GetBBox, ~Instance, FreeNodePool).
